# VoiceStage クイックスタート

Windows 11 x64：書き込み可能なフォルダーへ ZIP を展開し、`voicestage.exe` を起動します。右上で繁體中文・English・日本語を即時切替できます。小さい画面ではスクロールバー、キーボードでは Tab を使えます。

1. 左の台詞を選択して本文を編集し、「台詞を適用」を押します。追加・削除・並べ替えに対応。人物名、権利のある音声 ID、言語ヒント、感情、速度（0.5–2.0）を編集したら「人物を適用」を押してから人物を切り替えてください。Fish の音声言語は本文から自動検出されます。
2. JSON パスを入力して保存・読込します。TXT は同名 `.txt` を使用し、各行は `人物ID: 台詞`。有効な ID がない場合は最初の人物を使います。TXT は追加のみ、JSON は安定した台詞 ID を保持します。自動保存・Undo 履歴はありません。
3. 初期設定の Mock は 440 Hz の合成テスト音です。**本物の Fish Audio 音声ではありません。** 出力フォルダーを設定し、選択行または全体を生成して再生できます。本文の `[MOCK_ERROR]` は 429 エラーを再現します。削除後、選択行を手動再試行します。
4. 実際の音声は `s2.1-pro` または `s2.1-pro-free` を選び、自分のキーと使用権のある音声 ID を入力して送信を確認します。無料から有料へ自動変更しません。キーはメモリまたは既存 ENV のみで、設定に保存しません。`FISH_API_KEY` に対応。
5. LLM の下書き生成は音声生成と独立しています。完全な chat completions URL、モデル、キー、プロンプトを設定します。strict JSON schema 対応の提供者が必要です。下書きは確認してから追加でき、既存台詞を上書きしません。キーなしでも手動編集・テンプレートを使用できます。

毎回独立したフォルダーへ分割 WAV と manifest を保存します。全行成功時に結合 WAV と各音声の実際の長さに基づく SRT を出力します。字幕は単語認識ではありません。

取消は未送信キューのみ停止します。送信済みリクエストは完了・課金される可能性があり、最大 120 秒待機します。タイムアウト・サーバーエラー・不完全な音声は課金状態が不明です。アカウントを確認してから再試行してください。POST の自動再試行はありません。料金の概算は感情タグを含む UTF-8 bytes に基づき、初期値は US$15/100万 bytes（変更可能）です。

この版は mock HTTP と合成音でテストしました。**実際の Fish/LLM API は未検証です。** 無料 API 独自のデータ方針を確認してください。音声アップロード、クローン、モデル重み、CSV、単一リクエストのネイティブ複数話者合成は含みません。LICENSE と第三者ライセンス表記を保持してください。
