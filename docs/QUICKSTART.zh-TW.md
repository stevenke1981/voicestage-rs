# VoiceStage 快速開始

Windows 11 x64：解壓縮到可寫入的資料夾，執行 `voicestage.exe`。右上角可即時切換繁體中文、English、日本語。小螢幕使用視窗捲軸；Tab 可移動焦點。

1. 選取左側台詞，修改右側文字後按「套用台詞」。可增加、刪除、上下排序。角色有名稱、聲音 ID、語言提示、情緒與 0.5–2.0 語速，修改後按「套用角色」再切換角色。Fish 根據文字自動偵測語音語言，語言欄只供編輯及 LLM 提示。
2. 輸入 JSON 路徑後「儲存 JSON」；「開啟 JSON」讀取同一路徑。TXT 使用同名 `.txt`，每行 `角色ID: 台詞`；無有效角色 ID 時使用第一個角色。TXT 匯入只附加；JSON 保留穩定台詞 ID。沒有自動儲存或復原歷史，請經常儲存。
3. 預設 Mock 產生 440 Hz 合成測試音，**不是 Fish Audio 真實語音**。設定輸出資料夾，生成此句或全部，選句播放預覽。在台詞寫 `[MOCK_ERROR]` 可測試 429 錯誤；刪除該字串後手動重試。
4. 正式語音須選擇 `s2.1-pro` 或 `s2.1-pro-free`、填入自己的金鑰及有權使用的聲音 ID，再確認資料送出。免費與付費不會自動互換。金鑰只在記憶體或既有 ENV，不寫入設定。可用 `FISH_API_KEY`。
5. LLM 草稿與語音生成分開。填完整 chat completions URL、模型、金鑰與提示。提供者需支援 strict JSON schema。草稿只顯示於預覽，按「附加預覽草稿」才加入，不覆寫原台詞。沒有 key 仍可完整手動編輯及使用範本。

每次生成都有獨立資料夾、分段 WAV、manifest；全批成功才有整合 WAV 及依各段實際長度計時的 SRT（非逐字辨識）。Mock 與真實 API 來源在 manifest 明示。

取消只停止待處理佇列；送出的請求仍可能完成或收費，最多等待 120 秒。網路逾時、伺服器錯誤或不完整音訊可能已扣款，必須查核帳戶後再按重試。應用程式不自動重試任何 POST。計價顯示依 UTF-8 bytes，含情緒標籤，預設 US$15/百萬 bytes，可修改；只供估算。

本版僅以 mock HTTP 與合成音測試，**未呼叫真實 Fish/LLM API 驗證**。免費 API 有自己的資料政策；提交私人劇本前請閱讀官方條款。無音色上傳、克隆、模型權重、CSV 或原生多人單次合成。保留 LICENSE 與第三方授權聲明。
